Metadata

<meta>

Gives information about the page, inside <head>. Not visible.

Attribute Role
charset Character encoding (UTF-8).
name Kind of information (description, viewport...).
content Value of the information. 
<meta name="description" content="HTML metadata tags">
Not visible: search engines read it.

<title>

Text shown in the browser tab.

Attribute Role
(none) Only text inside. 
<title>Metadata | HTML Review</title>
Look at the browser tab.

<link>

Connects an external file, like a CSS stylesheet.

Attribute Role
rel Type of relation (stylesheet).
href Path of the file. 
<link rel="stylesheet" href="css/style.css">
The colors of this page come from css/style.css.
