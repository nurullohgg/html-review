Home & page structure

<html>

The root element that contains the whole page.

Attribute Role
lang Language of the page. 
<html lang="en">...</html>
This page itself is inside an <html lang="en"> tag.

<body>

Contains all the visible content of the page.

Attribute Role
class Name used by CSS. 
<body><p>Visible text</p></body>

Visible text

<h1> to <h6>

Headings from the most important (h1) to the least (h6).

Attribute Role
id Unique name of the heading. 
<h1>Title</h1>
<h6>Small title</h6>

Title

Small title
