Links & images

<a>

Creates a link to another page or file.

Attribute Role
href Address of the link.
target Where to open it (_blank = new tab). 
<a href="https://www.w3schools.com" target="_blank">W3Schools</a>
W3Schools

<img>

Displays an image. It has no closing tag.

Attribute Role
src Path of the image.
alt Text shown if the image fails.
width Width in pixels. 
<img src="images/cat2-1024x676.jpg" alt="A cat" width="300">
