Lists

<ul>

Unordered list with bullet points. Each item is an <li>.

Attribute Role
class Name used by CSS. 
<ul><li>Milk</li><li>Bread</li></ul>
  • Milk
  • Bread

<ol>

Ordered list with numbers or letters.

Attribute Role
type Kind of marker (1, A, a, I, i).
start First number of the list. 
<ol type="A" start="3"><li>First</li><li>Second</li></ol>
  1. First
  2. Second

<dl>

Description list: terms (<dt>) with descriptions (<dd>).

Attribute Role
id Unique name of the list. 
<dl><dt>HTML</dt><dd>Structure of a web page</dd></dl>
HTML
Structure of a web page
