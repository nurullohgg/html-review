Forms

<form>

Groups input fields to send data.

Attribute Role
action Where the data is sent.
method How it is sent (get or post). 
<form action="#" method="get"><button>Send</button></form>

<input>

A field where the user types or chooses data.

Attribute Role
type Kind of field (text, email, password...).
name Name of the data sent.
placeholder Hint text inside the field. 
<input type="email" name="mail" placeholder="Your email">

<select>

A drop-down list of <option> items.

Attribute Role
name Name of the data sent.
multiple Allows choosing several options. 
<select name="city"><option>Tashkent</option><option>Samarkand</option></select>
