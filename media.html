Multimedia

<video>

Plays a video file in the page.

Attribute Role
src Path of the video.
controls Shows play/pause buttons.
width Width in pixels. 
<video src="images/13004157_1080_1920_60fps.mp4" controls width="250"></video>

<audio>

Plays a sound file in the page.

Attribute Role
src Path of the sound.
controls Shows play/pause buttons.
loop Repeats the sound. 
<audio src="images/sound.mp3" controls></audio>

<iframe>

Shows another web page inside this page.

Attribute Role
src Address of the page.
width / height Size of the frame. 
<iframe src="text.html" width="400" height="200"></iframe>
